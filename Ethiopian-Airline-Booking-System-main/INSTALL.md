# Quick Installation Guide

## ⏱️ 2-Minute Setup

1.  **Install XAMPP**: Ensure you have XAMPP installed.
2.  **Deploy Code**: 
    Copy the `Ethiopian-Airline-Booking-System-main` folder to `C:\xampp\htdocs\`.
3.  **Start Apache**: 
    Open XAMPP Control Panel and click "Start" next to Apache.
4.  **Run**: 
    Open Browser -> `http://localhost/Ethiopian-Airline-Booking-System-main/`

## ✅ Requirement Checklist

- [x] PHP 8.0 or higher (Included in XAMPP)
- [x] Apache Web Server (Included in XAMPP)
- [x] SQLite Extension (Enabled by default in standard PHP)

## ❌ Common Mistakes to Avoid

1.  **Do NOT** double-click `index.html`. It won't work. The API needs PHP.
2.  **Do NOT** run `php -S localhost:8080` unless you know what you are doing. Use XAMPP (Port 80).
3.  **Do NOT** edit `database/airline_system.sqlite` manually. The app manages it.
