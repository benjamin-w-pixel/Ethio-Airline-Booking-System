About Ethiopian Airlines Booking System

⚡ System Features

  • ✅ Easy Registration: Quick passenger registration with secure data storage
  • ✅ Flight Booking: Browse and book available flights with real-time seat availability
  • ✅ Seat Selection: Interactive seat map for choosing preferred seats
  • ✅ Secure Payment: Multiple payment methods (Visa, PayPal, Bank Transfer, Mobile Money)
  • ✅ Booking Management: View, cancel, and delay your flight bookings
  • ✅ Flight Search: Search flights by destination and departure city
  • ✅ PDF Ticket Generation: Download your boarding pass as PDF
  • ✅ Analytics Dashboard: Admin revenue and booking analytics

👥 User Types

Passengers

• Register and create account

• Book flights and select seats

• View booking history

• Download PDF tickets

Administrators

• Add and manage flights

• View all passenger bookings

• Access revenue analytics

• System statistics dashboard

🗺️ Flight Destinations

Our system includes flights to major Ethiopian destinations:

Addis Ababa (ADD) Bahir Dar (BJR) Mekele (MQX) Gondar (GDQ) Hawassa (AWA) Dire Dawa (DIR) Axum (AXU) Lalibela (LLI)
